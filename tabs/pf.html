Private Flight — General
Three major roles: Butler, In-Flight Chef, Manual Check-In Agent. Gate Agent, Lounge Attendant, Pre-flight Services and Arm/Disarm can also be done on Private Flights.

The biggest thing to strive for is luxury. Make greetings more elaborate, treat passengers like royalty.

📋 Dress Code & Rules

· Follow proper dress code at all times — hair, face, accessories, name.
· Be professional throughout the entire flight.
· All roles must be done properly.
· Greetings must be more detailed and professional than normal flights.
· Use chat roleplays where necessary — Private Flights should be as realistic as possible.
· If questions arise, ask the Cabin Manager or Flight Host.
