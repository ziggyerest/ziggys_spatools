Mood lighting

Only the Cabin Manager changes the mood lighting. Change it at boarding, takeoff, cruising, descent and deboarding. Aeroware: enable stars only at cruising. Zerotech: select the same colour for all sections with shift. Vuela: set the colour, then click Set Color. Aeroware: select the colour, then click Change.
Takeoff: lighting off or black/grey before entering the runway. Descent: back to grey once the aircraft leaves the cruise pad. Deboarding: white or off-white yellow after parking.
